# About

This is a small test site for the Markdown Browser.

The browser fetches `.md` files, turns each one into a simple document model, and renders that model as a page. The same model can later become an outline, an OPML file, an SVG graph, or a stack of cards, without any change to the files.

> Does this add meaning to the document, or merely presentation machinery?

That's the test every feature has to pass.
